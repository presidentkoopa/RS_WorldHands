// RS_WorldHands -- the hand system's menus.
//
// ITS OWN ROOT, hooked directly into the engine's options menu rather than
// nested under RS_VR_Unified's. This package must be usable with Unified
// absent, and a Submenu pointing at a menu that does not exist is a dead row,
// not an error -- so depending on another mod's menu structure would leave a
// silent hole exactly when this ships alone.
//
// THIRTEEN PAGES AND FIVE OPTION LISTS, and the count is worth stating because
// an audit of this set on 2026-09-07 reported eleven. The two it missed were
// RS_HandsMainPlacement and RS_HandsOffPlacement -- the PLACEMENT SLIDER pages,
// the ones that write the PlacementCVars the renderer reads live. Losing those
// two loses the only working way to position a hand.
//
// ---------------------------------------------------------------------------
// THE ROOT BELOW IS NOT DECORATION. THREE SIBLINGS, NOT ONE.
//
// RS_HandsOptions links ONLY the two placement pages. Everything else --
// grab, distance grab, throwing, feedback, the aiming ray, what is grabbable,
// two-hand stabilize -- hung off RS_VRUnifiedOptions, which lived in the
// package this was lifted out of and is NOT here.
//
// So hooking "Hands" alone into the options menu compiles clean, loads clean,
// and leaves ten of the thirteen pages with nothing pointing at them. In a
// headset that reads as the grab system having been stripped out, when in fact
// every cvar, class and row is present and merely unreachable. Keep all three
// rows.

AddOptionMenu "OptionsMenu"
{
	Submenu "VR World Hands", "RS_WorldHandsOptions"
}

{
	Submenu "VR World Hands", "RS_WorldHandsOptions"
